# Policy digest (paste into every brief)

Research authority: search the web yourself when docs or dependency facts are missing or stale (primary sources first: Termux wiki, termux-packages, termux-app, Android and shell manuals); cite URLs; never guess. Target Termux: LF endings, `$PREFIX`/`$HOME`/`$TMPDIR`, no FHS paths. Verify, do not assume. No auto-commit; no `git add`. Smallest correct change; no over-engineering. Idempotent, fail-fast, quoted expansions, validated arguments. Data to stdout, logs and errors to stderr. Evidence: `git --no-pager`; no `head`, `tail`, or `less` on evidence; diffs through `diff-collect`; long output goes to a file and is read in ranges of at most 250 lines; a result without its end marker is truncated. Log prefixes `[*] [+] [-] [!] [?]` only in installers and general utilities; wrappers of system commands and CLI integrations keep native wording, streams, and exit codes, with no prefixes (identify them by role, not file name). Comments only for non-obvious reasons or Termux constraints, never for what the code does; block banners use exact-length hash borders. ShellCheck for sh/bash (project `.shellcheckrc`), none for zsh; shfmt via project `.editorconfig` with no style flags, diff-only for zsh.
