# Bug report

Delete a section that does not apply.

## Symptom
Exact error text and exit status.

## Environment
Host or Termux (rooted or not); shell, dialect, and shell version.

## Reproducer
The command or minimal script, and where it was run (host, termux-sim profile, device).

## Evidence
Trace excerpt with file:line, and relevant outputs. Intent check of the lines to change (history, comments). Full logs: `.artifacts/trace/<time>/`.

## Root cause
One sentence.

## Fix
What changed, and why it is the smallest change at the root cause.

## Verification
- Reproducer result before and after
- Lint SUMMARY line
- Idempotency (second run)
- One neighboring case

## Not verified on host
Device-only items, each with the exact command and the expected result.
