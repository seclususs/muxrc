# Review report

## Summary
- Verdict: approve | changes needed (N blocker, N major) | no findings
- Scope: files or diff summary; scope flags used
- Coverage: diff parts and line counts read in full; files read in full; skipped files; verify=ok|mismatch; references checked and unverified
- Lint: SUMMARY line and coverage

## Spec compliance (stage A)
- Criterion: met | unmet, with evidence
- Behavior that was not requested: none | list

## Findings
Order by severity: blocker, major, minor, nit. One block per finding.

### 1. blocker: short title (`path:line`)
- Fact: what the code does, as observed.
- Evidence: reproducer command and result (shell and version), or the rule violated and its source.
- Intent check: the commit or comment found for these lines, or none.
- Fix: the concrete change.

### 2. minor: short title (`path:line`)
- Same fields as finding 1.

## Unverified leads
- `path:line`: the suspicion and what would confirm it (no severity, no edit)

## Needs device (unverified)
- Item: exact command to run in Termux, and the expected result
